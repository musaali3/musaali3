## Featured Projects

### CourseTrackr  
A full-stack course grade and GPA tracking web application built with React, Flask, and SQLite.

The app allows students to add courses, record assessments, enter grades and weight percentages, calculate weighted course averages, and view an overall GPA summary.

**Tech:** React, Vite, Flask, SQLite, Flask-SQLAlchemy, CSS  
**Live App:** https://course-trackr.vercel.app/

### SentinelAI  
An autonomous AI incident response agent built for the TMLS Agentic Hackathon.

SentinelAI helps detect service issues, investigate possible causes, track incidents, and support response workflows through tools such as Jira and Slack integrations.

**Tech:** FastAPI, SQLAlchemy, SQLite, OpenAI API, React, Vite, Recharts, Jira REST API, Slack webhook
